# Software Requirements Specification (SRS)

## 5.3 Security Requirements

### Privacy Impact Checklist

#### 1. What personal data does the system collect, and why?

- Student name: Used to identify the user.
- University email: Used for account login and verification.
- Password: Used for secure authentication.
- Tasks and events: Used to provide productivity and scheduling features.

#### 2. How is the data stored, and who can access it?

- User information is stored securely in the application's database.
- Passwords are encrypted/hashed.
- Only authenticated users can access their own information.

#### 3. Can users see or delete their own data?

- Users can view and update their profile information.
- Users can delete tasks and events.
- Users can request deletion of their account data.

#### 4. ACM Code of Ethics Tie-In

This project follows ACM Principle 1.6: Respect Privacy by collecting only the information needed for the application's functionality and giving users control over their data.
