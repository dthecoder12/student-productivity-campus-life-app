# Core Features

- A unified dashboard that shows upcoming assignments, exams, work shifts, and campus events in one view.
- Assignment tracking with due dates, status (not started, in progress, completed), and reminders.
- A weekly schedule view that combines class times, work shifts, and events.
- Custom reminders and notifications for important deadlines and events.
- Simple task creation for personal to-dos that are not tied to a class.
- Basic filtering to view only school, work, or campus events when needed.
