# Team Norms

## Communication
We will communicate primarily through [Discord/Group Chat/Email] and check messages at least once per day on weekdays.

## Check-in Schedule
We will have a quick check-in meeting twice per week to review progress, blockers, and next steps.

## Conflict Resolution
If there is a disagreement, we will first discuss it directly and respectfully. If we cannot resolve it, we will document both perspectives and ask the instructor for guidance.

## Definition of Done
A task is considered "Done" when:
- The work is completed according to the issue description.
- The changes are committed and pushed to the repository.
- The team member responsible has walked through the work with the other team member.
- The related GitHub issue is closed.
